## Source checks

Full SHA-256 checksums match each original PNG to its library asset. Repeated files appear once. Different content is never discarded solely because it shares a filename. The machine-readable [inventory](artwork-inventory.json) records archive checksums, member filenames, image dimensions and PDF source pages. All entries are selectable in Admin → Page editor → Artwork category; search and visible counts help locate each collection.

Colour-Scheme.zip supplies 25 RGB swatches, available in Event branding and text colour controls. Containers-And-Frames.zip supplies 8 shapes with and without their original shadows. Dynamic-Logo-Extensions.zip supplies 8 arrangements in transparent, cream and reverse variants. Grey specimen placeholders are not shipped as final content: brand-colour placeholders use the supplied cream, and reverse content areas stay transparent. Logos retain their original lettering and geometry. The PDFs, AI and EPS versions are source production formats rather than duplicate browser thumbnails.
